# Gerador de Nomes com Redes Neurais

Projeto autodidata focado no estudo de redes neurais aplicadas à **geração de texto**, utilizando **Python** e **PyTorch**. O objetivo principal é treinar um modelo capaz de gerar nomes realistas a partir de diferentes bases de dados, como nomes norte-americanos, brasileiros ou até nomes fictícios (ex: Pokémons).

## Objetivo

Explorar conceitos fundamentais de aprendizado de máquina e redes neurais através da implementação prática de um modelo de geração de texto baseado em:

- **MLP (Multi-Layer Perceptron)**
- **SGD (Stochastic Gradient Descent)**

O projeto busca compreender como redes neurais podem aprender padrões linguísticos e gerar novas sequências de caracteres coerentes.

## Funcionalidades

- Treinamento de modelo com diferentes datasets de nomes
- Geração de novos nomes baseados nos padrões aprendidos
- Suporte a múltiplos idiomas e estilos
- Configuração simples de hiperparâmetros

## Tecnologias Utilizadas

- Python 3.x
- PyTorch
- Matplotlib

## Conceitos Abordados

- Tokenização de caracteres
- Codificação one-hot
- Embeddings simples
- Forward e backward propagation
- Função de perda (cross-entropy)
- Otimização com SGD
- Overfitting e regularização
